جواب‌های Claude حرف ندارند، فقط مشکل اینجاست که فارسی‌اش چپ‌چین و به‌هم‌ریخته در می‌آید. این افزونه با یک کلیک حلش می‌کند و توی کار بقیه‌ی چیزها هم اصلا دخالت نمی‌کند.

| 😖 قبلش                                       | 😍 بعدش                                              |
| --------------------------------------------- | ---------------------------------------------------- |
| جواب‌های فارسی چپ‌چین و درهم می‌آیند          | هر جواب تروتمیز راست‌چین می‌شود، با یک فونت خوش‌دست  |
| موقع تایپ، نشانگر و حروف بالا و پایین می‌پرند | همین که شروع کنی به نوشتن، کادر تایپ راست‌چین می‌شود |
| کد و انگلیسی قاطی متن، شلخته به نظر می‌رسند   | کد سر جای خودش می‌ماند، انگلیسی هم همین‌طور          |

## ✨ چرا عاشقش می‌شوی

- 🪄 **خودکار** — جهت متن را پاراگراف به پاراگراف خودش تشخیص می‌دهد؛ نه دکمه‌ای، نه تنظیماتی.
- 🌍 **زبان خودت** — فارسی را بی‌نقص می‌چیند و با عربی، اردو، کردی و باقی خط‌های راست‌به‌چپ هم راه می‌آید.
- 🔤 **تایپوگرافی تمیز** — فونت وزیرمتن همراهش می‌آید، با اندازه و فاصله‌ای که خودت تنظیم می‌کنی.
- ⌨️ **کادر تایپ هوشمند** — تا دست به نوشتن می‌بری، خودش راست‌چین می‌شود.
- 🧩 **کاری به کد ندارد** — بلاک‌های کد، diff و ترمینال چپ‌به‌راست و دست‌نخورده می‌مانند.
- 🎛️ **کنترل دستی با یک کلیک** — یک دکمه‌ی شناور خودکار / راست‌چین / چپ‌چین جهتِ کلِ گفتگو را پین می‌کند (`Cmd/Ctrl + Shift + 9`)؛ در چتِ Claude Code روی هر پیام هم یک کلید ⇌ هست.
- 🧠 **فقط Claude نه** — روی ChatGPT و Gemini هم کار می‌کند.
- 🔒 **کاملا روی دستگاه خودت** — صددرصد لوکال؛ نه سروری، نه ردیابی‌ای.

## 🚀 نصب

دو راه داری؛ نتیجه‌ی هر دو یکی است.

### راه سریع — یک دستور و خلاص

```bash
npx rtl-for-claude
```

- **منو**: با فلش‌ها انتخاب می‌کنی — اپ Claude Desktop، چت Claude Code یا
  Codex، یا خود افزونه‌ی VS Code.
- **برگشت**: دوباره اجرایش کن و گزینه‌ی حذف را بزن؛ همه‌چیز مثل اولش می‌شود.

ترمینال نمی‌خواهی؟ دو جایگزین هم هست:

- 🖱️ **دوبار کلیک**: فایل **Install RTL for Claude.command** را از
  [Releases](https://github.com/mahdigh99/rtl-for-claude/releases/latest)
  بگیر و بازش کن (بار اول: راست‌کلیک و بعد **Open**).
- 🤖 **با هوش مصنوعی**: آدرس ریپو را به Claude Code بده و بگو «راست‌چینش کن» —
  [راهنمایش](CLAUDE.md) توی ریپوست.

<sub>فقط [Node.js](https://nodejs.org) نسخه‌ی ۱۸ به بالا می‌خواهد. دو استثنا:
افزونه‌ی مرورگر از این منو نصب نمی‌شود (پایین همین صفحه است)، و روی ویندوز هم
فعلا از راه دستی برو.</sub>

### راه دستی — همه‌چیز دست خودت

خبری از جادو نیست: هر بخش یا اسکریپتی است که می‌توانی قبل از اجرا بازش کنی و
خط‌به‌خطش را بخوانی، یا پوشه‌ای که خودت توی مرورگر بارگذاری می‌کنی. دوست
نداری چیزی را ندیده اجرا کنی؟ این راه مال توست.

**مرورگر — Chrome / Edge / Brave**

1. پوشه‌ی [`browser-extension`](browser-extension) را دانلود کن.
2. آدرس `chrome://extensions` را باز کن و **Developer mode** را روشن کن.
3. روی **Load unpacked** بزن و همان پوشه را انتخاب کن. تمام. ✅

**مرورگر — Firefox**

1. آدرس `about:debugging` را باز کن و روی **Load Temporary Add-on** بزن.
2. فایل `browser-extension/manifest.json` را انتخاب کن.

**VS Code — Claude Code**

از **Marketplace**: عبارت **«RTL for Claude»** را جستجو کن (یا
[صفحه‌اش](https://marketplace.visualstudio.com/items?itemName=mahdigh99.rtl-for-claude)
را باز کن)، روی **Install** بزن، بعد **Developer: Reload Window** را اجرا کن.

یا با فایل **`.vsix`**: فایل `rtl-for-claude-vscode-*.vsix` را از
[Releases](https://github.com/mahdigh99/rtl-for-claude/releases) دانلود کن و توی VS Code
**Extensions ← `…` ← Install from VSIX…** را بزن.

افزونه هم نمی‌خواهی؟ `bash vscode-extension/apply-rtl.sh` خود چت را مستقیم پچ
می‌کند. راهنمای کامل: [vscode-extension/README.md](vscode-extension/README.md).

**VS Code — Codex**

راحت‌ترین راه همان افزونه‌ی **RTL for Claude** بالاست: اگر Codex نصب باشد،
خودش یک بار می‌پرسد که آن را هم راست‌چین کند و بعد از هر آپدیت Codex هم خودش
دوباره اعمالش می‌کند (تنظیم `rtlForClaude.codex.enabled`).

راه دستی‌اش هم پچ‌کننده‌ی جداست:

```bash
bash vscode-extension-codex/apply-rtl.sh
```

بعدش **Developer: Reload Window** را اجرا کن؛ این یکی را بعد از هر آپدیت
Codex باید خودت دوباره اجرا کنی و برگرداندنش هم با `--remove` است.

اسم این محصول در Marketplace حالا **Codex** است ولی پوشه‌ی نصبش هنوز شناسه‌ی
قدیمی `openai.chatgpt` را دارد — عادی است، نگران نشو. راهنمای کامل:
[vscode-extension-codex/README.md](vscode-extension-codex/README.md).

**اپ Claude Desktop — فقط macOS**

مخزن را دانلود کن، اگر خواستی اسکریپت را بخوان، بعد اجرایش کن:

```bash
bash desktop-app/apply-rtl.sh --install
```

**نتیجه‌ی نصب یک اپ دوم است به اسم Claude-RTL** — به Claude اصلی‌ات دست
نمی‌زند و آن هم مثل قبل کار می‌کند. اپ جدید کنار اپ اصلی نیست؛ در پوشه‌ی
Applications داخل هوم خودت (`~/Applications`) نصب می‌شود و راحت‌ترین راه
پیداکردنش Spotlight است: بنویس **Claude-RTL**. از این به بعد همان را باز کن.
بعد از هر آپدیت Claude Desktop یک بار دیگر اجرایش کن؛ `--remove` هم اپ دوم
را پاک می‌کند و همه‌چیز مثل روز اول می‌شود.

<sub>این روش Node.js و Xcode Command Line Tools می‌خواهد؛ اگر مطمئن نیستی،
`npx rtl-for-claude --doctor` می‌گوید چه چیزی کم است. راهنمای کامل:
[desktop-app/README.md](desktop-app/README.md).</sub>

## 🎛️ به سلیقه‌ی خودت

روی آیکن نوار ابزار بزن و همه‌چیز را همان‌طور که دوست داری تنظیم کن: حساسیت تشخیص، فونت (همراهِ افزونه یا فونتی که روی کامپیوترت نصب است)، اندازه‌ی متن، فاصله‌ی خط‌ها، دکمه‌ی شناورِ جهت، زبانِ پنجره‌ی افزونه، و این‌که روی کدام سایت‌ها فعال باشد — از جمله سایت‌های دلخواهِ خودت.

## ❓ سوال‌های پرتکرار

**بعد از آپدیت Claude همه‌چیز به‌هم ریخت. حالا چی؟**
افزونه‌ی مرورگر اصلا کاری به آپدیت ندارد و افزونه‌ی VS Code هم خودش را دوباره اعمال می‌کند — روی هر دو چت، اگر پوشش Codex را هم روشن کرده باشی. فقط پچ‌های دستی — اپ دسکتاپ، و چت‌ها اگر بدون افزونه پچ‌شان کرده باشی — همان یک دستور همیشگی را یک بار دیگر می‌خواهند.

**دقیقا به چه چیزی دست می‌زند؟**
به هیچ فایل اصلی‌ای. اپ دسکتاپ روی یک کپی جداگانه (Claude-RTL) پچ می‌شود و پچ‌های VS Code هم قبل از هر تغییری از فایل نسخه‌ی پشتیبان (`*.rtl-backup`) می‌گیرند. همه‌چیز هم آفلاین و روی سیستم خودت.

**ویندوز و لینوکس چی؟**
افزونه‌ی مرورگر و افزونه‌ی VS Code همه‌جا کار می‌کنند؛ پچ اپ دسکتاپ فعلا فقط macOS است.

**چطور همه‌چیز را به حالت اول برگردانم؟**
دستور `npx rtl-for-claude` را اجرا کن و گزینه‌ی حذف را بزن، یا به هرکدام از اسکریپت‌ها `--remove` بده. افزونه‌ها هم مثل هر افزونه‌ی دیگری حذف می‌شوند.
